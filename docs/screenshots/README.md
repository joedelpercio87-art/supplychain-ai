# Screenshots

This directory is reserved for genuine screenshots captured from the locally running SupplyChain AI application. No screenshots are fabricated or included by the documentation pass.

When ready, add these files and reference them from the root README or portfolio materials:

- `dashboard-overview.png` — the dashboard header, KPIs, and question area.
- `investigation-analysis.png` — an actual generated answer with its facts, interpretation, policy, actions, and evidence gaps.
- `context-trace.png` — an actual investigation trace and retrieved policy sources.

Capture screenshots from the local synthetic demonstration, and check that no credentials, local filesystem paths, or unrelated personal information appear in the image. Keep the displayed question and answer consistent with the repository’s synthetic-data disclaimer.
